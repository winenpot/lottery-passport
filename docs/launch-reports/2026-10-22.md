   enabled it, confirmed via `scripts.server_check`.
2. **Reset-test CI bug found and fixed in 4 steps**, each one exposing the
   next layer: (1) an unscoped `UPDATE` in a test marked every
   `redemption_codes` row in the shared CI database redeemed; scoping it
   to the test's own batch wasn't enough because (2) `coin_ledger_entries`
   and `audit_log` have a database trigger that **permanently** rejects
   UPDATE/DELETE (same append-only guarantee production relies on), so no

   throwaway Postgres database per run, migrated with the real alembic
   chain, and drops it afterward — so this test can never again be
   poisoned by another module sharing one CI database. Commits
   `df2cb8d`, `bcfb1ad`, `1a94019`. CI green: run `39760817858`.

   had the office range; added VPN/mobile IPs (temporary, flagged for a
